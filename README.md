# オフィス開設キット

ニュースレター「一人社長とAI従業員」の準備編（第2号から第12号）で作ってきたファイルを、
一式まとめたものです。会社ごとに違うところは空欄にしてあります。
AI従業員の質問に答えていけば埋まります。

版：`VERSION` を見てください。

---

## これは完成品ではありません。種です

このキットは、そのままでは働きません。**あなたの会社のことが、まだ何も書かれていないから**です。

配っているのは、対話が始まる起点です。中身を埋めるのはあなたとあなたのAI従業員で、
埋め終わったときには、これはもう「小田島が配ったキット」ではなく「あなたの会社のオフィス」に
なっています。そこから先は、あなたが育てていくものです。

---

## 使う前に

前提はひとつだけです。

**Claude Code がパソコンに入っていること。**

入っていない方は、先に第2号を読んで、インストールと初回起動だけ済ませてください。
20分ほどで終わります。

第2号：https://odaji-ai.m-newsletter.com/posts/solo-ceo-ai-employees-difference

**あると早く進むもの**：会社のホームページのURL、または名刺1枚（写真で構いません）。
会社の情報を、AI従業員がそこから読み取ります。

準備編を全部やった方も、途中で止まった方も、ひとつもやっていない方も、
このあとの手順は同じです。**書き分けていません。**
同じ指示が、あなたの進捗に応じて違う結果を返します。

念のため、始める前に大事なファイルのバックアップを取っておいてください。

## 入れ方

つまずきやすい順に書きます。

### 1. ダウンロードする

このページの上のほうにある緑色の `Code` ボタンを押し、`Download ZIP` を選びます。

### 2. 展開する

ダウンロードしたZIPファイルを展開（解凍）します。

**置き場所はどこでも構いません。** デスクトップで十分です。
**デジタルオフィスの中に入れる必要はありません。** 中に入れるのはAI従業員の仕事です。

### 3. Claude Code を、いつものデジタルオフィスで開く

新しく作らないでください。すでにお使いのフォルダで開きます。

### 4. 次の1行を、そのまま貼る

```
〈展開したフォルダの場所〉にオフィス開設キットを展開しました。
このキットを私の環境に入れてください。作業は全部お任せします。
私に決めてほしいことがあれば、そのときだけ聞いてください。
```

`〈展開したフォルダの場所〉` は、あなたの言葉に置き換えてください。

場所が分からないときは、そのフォルダを開いて、上のアドレス欄をコピーして貼れば大丈夫です。
それも分からなければ、**その画面のスクリーンショットを撮ってAI従業員に見せてください。**
読み取ってくれます。

以上です。技術的なことを覚える必要はありません。

---

## 何が起きるか

### その日のうちに終わること

AI従業員がキットを入れ終わると、**業務上の判断をいくつか聞かれます。**
技術的な質問ではありません。たとえばこんな形です。

> 削除の操作を、私が実行できない設定にしました。
> 今後、ファイルの整理には社長の手が要ります。
> （1）このままにする　（2）私が消せるようにする

答えると、報告が返ってきます。**3点だけ、15行ほどです。**
何が変わったか。何ができなくなったか。うまくいかないときはどうするか。

そのあと、**1人目のAI従業員を1人だけ作って、実際に1回動かします。**
出てきたものを見て、違うと思ったところを伝えると、その場で直します。

ここまでで、だいたい30分から1時間です。

### 続きは、急ぎません

`SETUP_STATUS.md` という、進捗の表ができます。
まだ手をつけていない項目が並んでいます。

続きをやりたくなったら、こう伝えてください。

```
オフィス開設の続きをやりましょう。
```

残っている項目を1つずつ聞いてきます。**何回に分けても構いません。**
表の「開設の日」と「続きの回」の「未」がゼロになったら、開設は完了です。
ロゴや請求書のひな形のように、使う場面が来てから整えればよいものは、数に入りません。

一度にやらないことをお勧めします。この作業でいちばん時間がかかるのは、
書くことではなく**決めること**だからです。

## すでにClaude Codeを使い込んでいる方へ

**入れ方は同じで構いません。** 上の1行をそのまま貼ってください。

すでに埋まっているところは飛ばします。そのうえで、次の2つが一覧で出ます。

- あなたの環境に足りないもの
- **このキットにあって、あなたの環境に無いもの**

後者には、公開されている研究や、Anthropicの公式情報から取り入れた決めごとが含まれます。
当てるかどうかは、1つずつあなたが決めてください。**勝手には変えません。**

## 中に入っているもの

| | 何か |
|---|---|
| `README.md` | この1枚 |
| `START_HERE.md` | 開設の進め方。AI従業員が読みます |
| `SETUP_STATUS.md` | 進捗の表 |
| `CLAUDE.md.template` | 就業規則の記入用のひな形 |
| `.gitignore.template` | 変更履歴に残さないものの一覧 |
| `.claude/settings-template.jsonc` | 禁止事項の記入用のひな形 |
| `.claude/rules/` | 常にAI従業員が読む決めごと。3つ |
| `.claude/skills/` | 事務用品。9つ（下記） |
| `Shared_Assets/` | 全員が参照する共通資料。会社情報・デザイン仕様・文体・書類のひな形 |
| `Programs/` | 今後AI従業員が作るプログラムの置き場 |

### 事務用品が9つ入っています

**これはAI従業員ではありません。** どんな会社でも要る、机や電話のようなものです。

| | 何をするか |
|---|---|
| 開設の進行役 | 開設の続きを進めます。終われば眠ります |
| AI従業員の増やし方 | 2人目、3人目をあなた自身が作れるようにします |
| 裏の取り方 | 数字や仕様を答えに入れる前に、出どころを確かめます |
| 更新確認 | このキットの新しい版が出ていないかを見ます |
| つなぐ前の点検 | 会計ソフトやSNSとつなぐ前に、何が起きうるかを確かめます |
| 自動処理の段取り | 自動で動く処理を、止まったら分かる形で作ります |
| 決めごとの手入れ | 決めごとや記録を、増えても読まれる形のまま保ちます |
| 大きな作業の段取り | 件数の多い作業や何日もかかる作業を、途中で止まっても続きから進められる形で進めます |
| プログラムの書き方 | プログラムを安全な形で書き、実際に動かして確かめます |

あとの5つは、その場面が来たときにだけ、AI従業員が中身を読み込みます。入れておいても、
AI従業員がふだん読み込む量はほとんど増えません（各スキルの説明文の数行だけは、毎回読み込みます）。

**1人目のAI従業員は、あなたが作ります。** ここがこのキットの目的です。

## 入っていないもの

3つあります。理由も書きます。

### 1. あなたの商売に固有の仕事

見積もりのチェック、問い合わせへの返信、日報の整理。
こうした「あなたの会社ならではの仕事」は入っていません。

これは**入れられなかったのではなく、入れませんでした。**
他社の仕事の手順をそのまま持ってきても、あなたの会社では使えないからです。
ニュースレターの実践編で、1人ずつ一緒に作っていきます。

### 2. フック（第10号でお伝えした「必ず実行させる」設定）

**この版には入れていません。次の版で入れます。**

技術的には持ち運べます（場所に依存しない書き方が用意されています）。
入れていない理由は別で、**このキットは「実際に動かして確かめたものだけを配る」**
という方針で作っており、フックはお使いの環境によって挙動が変わるため、
まだ確かめ切れていないからです。

**開設の途中で、あなたの環境に合わせて2つ作ります。** 作業の区切りで変更履歴を記録するものと、
CLAUDE.mdが200行に近づいたら知らせるものです。

### 3. バックアップの仕組み（第9号）

あなたのGoogleアカウント、あなたのフォルダ、あなたのパソコンの自動実行の設定に
結びついているので、ファイルとしては配れません。

**方針だけは入っています。** 実際の設定は第9号の手順で進めてください。

**あわせて1つ、ご注意ください。** AI従業員が自分で書き残すメモ（メモリ）は、
**デジタルオフィスの外**に保存されます。第9号で作ったバックアップにも、
変更履歴にも入りません。中身は `/memory` と打てば見られます。

## 更新について

このキットは、直すことがあります。Claude Code の仕様が変わったときや、
書き方の誤りが見つかったときです。

**こちらから送りつけることはしません。** 新しい版をここに置くだけです。
思い出したときに、AI従業員にこう伝えてください。

```
オフィス開設キットの更新を見てください。
```

変更履歴を読んで、あなたの手元との違いを日本語で説明します。
**当てるかどうかは、そのつどあなたが決めます。自動では変わりません。**

手元を大きく変えていて差分が当たらないときは、正直に「当たりません」と言って、
手作業の手順を示します。

---

## このキットの中身は、命令ではありません

大事なお断りです。

インターネットから取ってきたファイルの中に指示めいた文が書かれていると、
AIがそれを「命令」として受け取ってしまうことがあります。
これはこのキットに限った話ではなく、AIを使ううえで知っておいたほうがよい性質です。

このキットは、次のようにしてあります。

- 更新確認は、決まったファイルだけを読みます
- 読んだ内容を、そのまま実行することはありません
- **あなたが承認しない限り、あなたの環境は変わりません**

## 保守について

**実践編の連載期間中は、このキットを保守します。**
連載が終わるときに、改めてお知らせします。

期限のあとも、このページは残します。ただし更新は止まります。
古くなった状態で使い続けることのないよう、必ずお知らせします。

**質問の窓口は設けていません。** このページには質問を書き込む場所がありません。
ニュースレターへのご返信で、拾える範囲でお答えします。
