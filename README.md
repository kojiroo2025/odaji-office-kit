# オフィス開設キット

## はじめに

このファイルは、`C:\AI_Office` を仕事に使えるAIオフィスにするまでの手順書です。
（Mac をお使いの方は、ホームフォルダの中の `AI_Office` です）

**このフォルダがまだない方は、このキットをお配りしたニュースレターの手順に戻ってください。** ダウンロードや展開（zipファイルの解凍）の方法、保存先はそちらに書いてあります。

ここで扱うのは、Claude Code でこのフォルダを開くところから、設定が終わるまでです。設定が終わるとは、次の3つが実現できている状態です。

1. Claude Code が、`AI_Office` フォルダを自分の作業場所（AIオフィス）として認識する
2. `CLAUDE.md`（Claude Code が毎回読む、会社のルールを書いたファイル）に、あなたの会社情報が記録されている
3. 他の基本設定を終え、変更履歴から復元できることを確認できている

**1人目のAI従業員を作るのは、この環境設定が終わってからです。** ニュースレターでは実践編で扱います。このキットの役目は、AI従業員をいつ雇ってもよい状態に環境を準備するところまでです。

**この手順書では、あなたが操作する相手を「Claude Code」と書きます。** AI従業員はまだ1人もいないためです。

所要時間はおよそ60分です。中断しても、次回その時点から再開できます。

## Claude Code にさせない操作（念のためにご覧ください）

このキットには `.claude/settings.json` という設定ファイルが入っています。**Claude Code に勝手にさせると危ない操作を書いてあるファイル**です。**あなたが明示的に指示または承認しない限り、この設定は変わりません。** 開設が終わると、次の6つの操作が書かれた状態になります（6は、第2部の方の答えによって一部を残すことがあります）。

| | Claude Code にさせない操作 |
|---|---|
| 1 | フォルダやファイルを、あなたの承認なしでまとめて削除する（`rm -rf`） |
| 2 | データをインターネットへ送る、インターネットから取りに行く（`curl`・`wget`） |
| 3 | インターネット上に置いた変更履歴の控えを、手元の内容で強制的に上書きする（`git push --force`） |
| 4 | 接続用のIDやパスワードが入ったファイルを読む（`.env`・`.pem` など） |
| 5 | パソコンの管理者の権限で実行する（`sudo`） |
| 6 | Gmail などの外部サービスで、メールの送信・予定の招待・ファイルの共有などを行う。Chrome や画面を操作する（開設の日に、Claude Code が名前を読み取って禁止します。第2部の方には、禁止するかどうかを聞きます。あとから1つずつ使えるようにできます） |

**この設定の考え方は、ニュースレター第8号でお伝えしました。** なぜこの5つなのか、ご自分の会社では何を足せばよいのかを知りたい方は、そちらをご覧ください。

https://odaji-ai.m-newsletter.com/posts/ai-employee-safe-design-one-person-ceo

# 第1部　はじめて Claude Code を使う方

## 手順1　Claude Code を起動する

ニュースレター第2号で入れたアプリです。デスクトップのアイコン、またはスタートボタン（画面の下にある Windows のマーク）から起動してください。

**アプリの名前は `Claude` です。** 起動したら、**画面の左上に並んでいる3つのボタンのうち、いちばん右**をクリックして、Claude Code を選択してください。**`</>` マークが付いています。**

> **バージョンによって見え方が変わります。** `</>` のとなりに `Code` という文字が付いているバージョンと、マークだけのバージョンがあります。どちらも同じ場所です。**いちばん右、というのは変わりません。**

ログインや更新を求める画面が表示されたときは、第2号の起動手順のとおりに進めてください。
https://odaji-ai.m-newsletter.com/posts/solo-ceo-ai-employees-difference

## 手順2　`AI_Office` フォルダを Claude Code の作業場所（AIオフィス）に指定する

Claude Code を起動して最初にやることは、Claude Code の作業場所を `AI_Office` フォルダに設定することです。こうすることで、Claude Code は自分のAIオフィスが `AI_Office` フォルダだと認識し、あなたからの指示をそのフォルダ内で行うようになります。

次の手順で設定してください。

1. 左側の一覧のいちばん上にある**「＋ 新規」**（または「＋ 新規セッション」）をクリックしてセッションを開始します。
2. **中央下の入力フィールドのすぐ上**に、いま開いているフォルダの名前が小さく表示されています。**そこをクリックします**（`C` の1文字だけのこともあります。どんな表記でも、そこをクリックしてください）。
3. いちばん下にある**「フォルダを開く...」**をクリックします。
4. フォルダを選択するダイアログで `AI_Office` を選びます。
   - **Windows**：左側の一覧から「PC」→ `(C:)` と付いているものを開くと、その中にあります。
   - **Mac**：ダイアログが表示された状態で `command` と `shift` と `H` を同時に押すとホームが開きます。
5. `AI_Office` を1回クリックして選び、右下のボタン（「フォルダーの選択」または「開く」）をクリックします。

**「このフォルダのファイルを信用しますか」というダイアログが表示されたら、許可する側（`Yes` で始まるほう）を選んでください。** 英語のこともあります。**これを許可しないと、Claude Code を正しく使うことができません。**

最後に、手順2の2で見た場所をもう一度確認してください。**`AI_Office` になっていれば成功です。**

> **ここがいちばん間違えやすい場所です。** Claude Code は、開いたフォルダの中だけで作業します。**必ず `AI_Office` フォルダを選択してください。** その1つ上（`(C:)` やダウンロード）を選ばないでください。
> 間違えて選んでしまっても、手順2をもう一度やれば直ります。

> **フォルダの指定は、はじめてセッションを立ち上げたときだけです。** 次から「＋ 新規」で新しいセッションを始めるたびに、`AI_Office` を指定し直す必要はありません。前のセッションの設定がそのまま受け継がれます。何かの事情で別のフォルダで作業したいときだけ、手順2の2〜5をもう一度行ってください。

## 手順3　オフィス開設の指示を貼る

**下の枠の中の文を、そのまま Claude Code に貼り付けます。** これが開設の合図です。

```
オフィスを開設しましょう。事前に指示されている順番で進めてください。
```

**貼り方**

1. 上の枠の中の文章をすべて選択し、右クリックして「コピー」。
2. Claude Code の入力フィールドを1回クリックしてから、右クリックして「貼り付け」。
3. `Enter` を1回押すと、Claude Code が中身の確認と初期設定を始めます。

（「貼り付け」が表示されないときは `Ctrl` を押しながら `V`。Mac は `command` と `V`）

**初期設定には数分かかります。** 画面が動いているあいだは、そのままお待ちください。

**終わると、Claude Code が結果を報告し、最初の質問をします。** そこから先は、対話しながら進みます。**第3部を開いて、読みながらお進みください。**

# 第2部　すでに Claude Code を使っている方

## このキットを入れると、何が変わるか

このキットは、Anthropic が公式に提供している設定の書き方に沿って作ってあります。また、研究者たちが発表してきた最新の知見や論文のうち、私が実際に運用しながら見つけた設定が入っています。

つまり、すでにお使いの環境を、公式の標準と、現時点の最適な運用方法に合わせてブラッシュアップできます。

すでにあるファイルを上書きはしません。キットにあって手元にないものを、Claude Code と壁打ちしながらあなたに選んでもらうという方法で、AIオフィスに実装していきます。

## 手順1　これまで Claude Code で使ってきたフォルダの場所を確認する

Claude Code の入力フィールドのすぐ上に表示されるフォルダのことです。このフォルダへのパスが分からない場合は、Claude Code に聞いて教えてもらいましょう。

入力フィールドに、次の文を貼り付けます。

```
Claude Codeが標準で使うフォルダの場所を、フルパスで教えてください。
```

`C:\Users\〈あなたの名前〉\MyOffice` のような形で返事が戻ります。これがあなたのフォルダとそこまでのパスです。

## 手順2　`AI_Office` を、そのフォルダの中へ移動する

エクスプローラー（Mac は Finder）を開き、**手順1で返ってきたパス全体を、上のアドレス欄に貼り付けて** `Enter` を押します。これまで Claude Code で使ってきたフォルダが開きます。

そこへ `AI_Office` をフォルダごと移動してください。

```
C:\MyOffice\              ← これまで Claude Code で使ってきたフォルダの例
├ CLAUDE.md
├ .claude\
├ 01_作業中\
├ 02_成果物\
└ AI_Office\              ← ここへ移動する
   ├ CLAUDE.md
   ├ .claude\
   └ Shared_Assets\
```

**中に入れる理由**：Claude Code は、開いたフォルダの外を読むとき、そのつどあなたに承認を求めます。中に入れておけば、承認なしで比較できます。

## 手順3　比較のプロンプトを貼る

次の文を、そのまま貼り付けます。

```
いま開いているフォルダの中に、AI_Office というフォルダを置きました。
これはオフィス開設キットです。
AI_Office/START_HERE.md を読んでから、いまのあなたの環境と比較してください。

就業規則（CLAUDE.md）・ルール・禁止事項・スキルは、キットにあって私の環境にないものをリストにしてください。
これを適用するかどうかは、私が1件ずつ決めます。
勝手に変えずに、一つずつ私と壁打ちしながら進めてください。
私がOKを出したものは、あとでまとめて適用してください。

会社の情報やロゴを入れる空のフォルダは、私に聞かずにそのまま置いてください。
```

## 手順4　1件ずつ決める

**キットの中身は、2種類に分かれます。**

| | 何を | どうなるか |
|---|---|---|
| **A** | 就業規則（`CLAUDE.md`）・ルール・禁止事項・スキル | **1件ずつ示されます。**入れるかどうかを、あなたが決めます |
| **B** | 会社の情報・ロゴ・請求書などのテンプレートを入れる**空の入れ物**（`Shared_Assets` など） | **聞かれません。**お使いのフォルダになければ、そのまま置かれます |

**Bは、あなたの環境にある何かと重なりません。** だから比べる意味がなく、**置くだけです。**

**Aでも、そのファイルがお使いのフォルダにまだない場合は、聞かれません。** 比べる相手がいないので、**そのまま置かれます。** 聞かれるのは、**すでに同じファイルをお持ちで、その中身に違いがあるとき**だけです。

**ただし、禁止事項（`.claude/settings.json`）だけは別です。** お持ちでない場合も、**必ず1件ずつ聞かれます。** 禁止は「できることを減らす」設定なので、**黙って入れると、いままでできていた操作が急にできなくなる**からです。

**Aについて、**「何が違うか」「適用すると何が変わるか」が1件ずつ示されます。適用するものは「入れる」、適用しないものは「入れない」と答えてください。

**適用して損になる設定はありませんので、すべて「入れる」をおすすめします。**

どこに足すかは、Claude Code が判断します。**あなたが書いたものを置き換えることはありません。** そのつど尋ねる必要はありません。気になるものだけ、「どう入れますか」と聞いてください。そして、Claude Code の判断が適切でないと感じたら、あなたの希望を伝えてみてください。

決めた結果は、適用しなかったものも含めて `SETUP_STATUS.md` の末尾の表に記録されます。

## 手順5　そのまま第3部へ進む

適用が終わったら、**そのまま第3部へお進みください。**

**`AI_Office` フォルダは、まだ削除しないでください。** 第3部の手順は、そのフォルダの中に書かれています。**先に消すと、続きができなくなります。**

片づけは、**第3部がすべて終わったあと**に行います（第3部の末尾でご案内します）。

**①の方も②の方も、この18項目を順に進めてください。** Claude Code がこの順に進めます（17と18は、パソコンの操作に慣れた方向けです。詳しくは13〜18の説明をご覧ください）。

**ただし、第2部から来られた方には、もう1問増えます。**いまお使いのフォルダで Gmail などの外部サービスを使っている場合があるので、**Claude Code がそれらを使うことを、このフォルダで禁止するかどうか**を聞かれます。第1部の方には、この質問は出ません（Claude Code が最初から禁止し、結果だけを伝えます）。

| | 聞かれること |
|---|---|
| 1 | 会社のホームページのURL（または名刺の写真） |
| 2 | 上のURLから読み取った会社情報が合っているか |
| 3 | これから作るファイルを、どのフォルダに入れるか（案が示されます） |
| 4 | 会社のロゴとブランドカラー |
| 5 | 会社のミッション・ビジョン・行動指針 |

（Git がインストールされていない場合は、途中でインストールしていただきます）

**区切りごとに、Claude Code が現在地を知らせます。**

```
【報告】
README 第3部の3〜6「保存先とファイル名を決める」が終わりました。
次は、第3部の7〜9「変更履歴（Git）の記録を開始し、履歴から復元できることを確認する」です。
次の手順に進んでよろしいですか？
```

**Claude Code が知らせる番号は、この第3部の1〜18の番号と同じです。**

1項目終わるごとに `SETUP_STATUS.md` という表に記録されているので、途中でやめても、続きから再開できます。

## 1〜2　会社の情報を知らせる

（1　就業規則〔`CLAUDE.md`〕に、会社名と代表者名を書く／2　会社の情報を `Shared_Assets/Company_Info.md` に書く）

**Claude Code が、会社のホームページか名刺からあなたの会社情報を読み取ります。** あなたが1つずつ入力する必要はありません。

ホームページや名刺がない場合は、「ない」と言ってください。Claude Code が必要な情報を尋ねてきますので、それにお応えください。

読み取る項目：**会社名・代表者名・住所・電話番号・メールアドレス**。

読み取った内容は、そのままあなたに示されます。**違うところだけ指摘してください。** 埋まらない項目は「未定」と記録され、後に必要になったときに聞かれます。

## 3〜6　保存先とファイル名を決める

（3　AIオフィスの場所を就業規則に書く〔初期設定で Claude Code が済ませています〕／4　これから作るファイルの保存先を決める／5　ファイル名の付け方を決める／6　記録に残すことの方針を決める）

**これからの業務で Claude Code を使って作るファイルの保存先**を決めます。

案が示されるので、変えたいところだけ指摘してください。ファイルの命名規則（`YYMMDD_内容`）は、キットの既定にしたがってください。

## 7〜9　変更履歴（Git）の記録を開始し、履歴から復元できることを確認する

（7　変更履歴の記録を開始し、復元テストを行う／8　ファイルの削除の扱いと、外部サービスの禁止を伝える／9　禁止事項が、このパソコンでどこまで効くかを伝える）

変更履歴（Git：ギット。ファイルの状態を記録しておき、記録した時点の状態へ戻せる仕組み）の記録を開始します。これを記録しておけば、誤ってファイルを削除しても、記録した時点の状態に戻すことができます。

**Git は必須です。** 少し手間がかかるかもしれませんが、次の手順で進めてください。

Claude Code がまず、このパソコンに Git がインストールされているかを確認します。されていなければ、Claude Code が「Git がインストールされていません」と伝えてきます。「インストールのしかたを教えてください」と答えてください。

インストールが終わったら、Claude Code にこう指示してください。「Git をインストールしました。変更履歴の記録を開始してください」。

> **ここで「まだインストールされていません」と言われることがあります。** インストールのしかたを間違えたのではありません。**Claude のアプリは、起動したときのパソコンの状態のまま動いているので、あとからインストールしたものを見つけられないのです。**
>
> **アプリをいったん終了して、もう一度起動してください。** ここまでに決めたことは、すべてフォルダに保存されています。開き直したら、**さきほどまで開いていたのと同じフォルダ**を開いて、**「オフィス開設の続きをやりましょう」**と伝えれば、続きから再開できます。
>
> **第2部から来られた方は、`AI_Office` ではなく、これまで Claude Code で使ってきたフォルダを開いてください。** `AI_Office` を開くと、最初からやり直しになります。

すでにインストールされていれば、Claude Code が自動的に記録を開始し、続けて次の復元テストを行い、結果を報告します。あなたの操作は要りません。報告を確認し、問題なければ「OK。次に進もう」とだけ言ってください。

1. テスト用ファイルを1つ作って、記録する。
2. そのファイルを削除する。
3. 記録から元に戻す。
4. 戻したファイルの中身が、削除する前と同じことを確かめる。

4まで確認できたら、復元テストは終わりです。

**続けて、Claude Code からファイルの削除の扱いが伝えられます。** 変更履歴で元に戻せるようになったので、削除はこのまま Claude Code にも任せられる設定にしておくこと、削除する前には必ずあなたの承認を得ること、の2つです。**Claude Code にファイルを削除させたくない場合だけ、「ファイルの削除を禁止してください」と伝えてください。** これで、7〜9は終わりです。

## 10　共通資料を、Claude Code が必ず参照するようにする

`Shared_Assets/` にある4つのファイル（会社の基本情報、資料の作り方、文章の決まり、請求書などのテンプレート）を、Claude Code が毎回参照するように設定します。

**この10は、Claude Code がしてくれます。あなたは承認するだけです。**

## 11〜12　ロゴとブランドカラーを伝える

（11　ロゴ／12　ブランドカラー）

次に、Claude Code からロゴとブランドカラーについて尋ねられます。

- **ロゴ**：エクスプローラー（Mac は Finder）で、`AI_Office` の中の `Shared_Assets` フォルダへ、画像ファイルを入れてください。入れ終わったら「入れました」と伝えてください。**この会話に貼り付けないでください。** 貼り付けた画像は、Claude Code がファイルとして保存できません。
- **ブランドカラー**：色の名前でも、カラーコード（`#C62828` のような形）でも構いません。複数の色を伝えて、どう使い分けるかを Claude Code と相談することもできます。

**まだ決まっていなければ、そう伝えてください。** 保留として記録され、準備できたときに設定できます。

## 13〜18　残りの6項目

ここまでで12項目です。続けて、残りの6項目を設定します。

| | 何を |
|---|---|
| 13 | **会社のミッション・ビジョン・行動指針**にあたるものを `CLAUDE.md` に書く（1つか2つで構いません） |
| 14 | 区切りごとに変更履歴へ自動で記録する設定（フック） |
| 15 | **`CLAUDE.md` の行数が増えてきたら知らせる設定**（フック） |
| 16 | **接続用のIDやパスワード（APIキー・アクセストークン）を、鍵を保管する専用フォルダ（`C:\AI_Office_Secrets` など）へ移動する** |
| 17 | **AIオフィスのバックアップの作成**（既定はニュースレター第9号の方法＝Google Drive。OneDrive・外付けディスクなども選べます） |
| 18 | そのバックアップから、実際に復元できることの確認 |

**17と18は、パソコンの操作に慣れた方向けの作業です。** Google Cloud の画面での操作などがあり、難易度が高いためです。**パソコンの操作に慣れていなければ、16までで開設作業を終えても構いません。** 16が終わると、Claude Code から、17と18を進めるか見送るかを聞かれます。

見送った場合も、Claude Code が誤って削除したファイルは、変更履歴で元に戻せます。ただし、変更履歴はこのパソコンの中にあるため、**パソコンが故障すると、AIオフィスのファイルは戻せなくなります。** パソコンの操作に慣れてから、「オフィス開設の続きをやりましょう」と伝えれば、いつでも17から始められます。

**16・17・18は、この順に行います。** 先にバックアップを作ると、**接続用のIDやパスワードまで一緒にバックアップの保存先へ複製されてしまう**ためです。複製された鍵は過去のバックアップに残り、すぐには削除できません。

**16・17・18では、あなたの承認や操作が必要です。**

- **16（鍵の移動）**：鍵を含む可能性があるファイルを Claude Code が探し、ファイルの場所を示します。専用フォルダの作成とファイルの移動は Claude Code が行います（ファイルの中身は読みません）。**あなたは、移動してよいかを承認します。**
- **17（バックアップ）**：Claude Code から、バックアップの保存先を尋ねられます。第9号の方法ですでに設定してあれば、Claude Code が実行の記録を確かめます。これから Google Drive に作る場合は、**Google Cloud の画面で接続用の鍵を発行する操作だけ、あなたが行います。** 画面の写真（スクリーンショット）を撮って Claude Code に貼り付ける方法を案内されるので、写真を貼りながら、1つずつ操作を進めます。この方法は、これから外部サービスとつなぐときにも使います。 バックアップのプログラムと毎日の自動実行の設定は、Claude Code が作ります。
- **18（復元の確認）**：Claude Code がテスト用ファイルをバックアップから別のフォルダへ戻し、中身が同じかを確かめます。**あなたは、進めてよいかを承認します。**

## 途中でやめるとき

**1項目終わるごとに記録されるので、途中でやめても、続きから再開できます。**

再開するときは、Claude Code を開いて（フォルダの指定は不要です）、こう伝えてください。

```
オフィス開設の続きをやりましょう。
```

## 第2部から来られた方へ：最後に `AI_Office` を片づける

**開設作業がすべて終わったら**（17と18を見送った場合は16が終わったら）、`AI_Office` フォルダを削除してください。役目は終わりました。

**Claude Code に指示しても、消せない設定になっていることがあります。** エクスプローラー（Mac は Finder）でご自分で削除してください。

削除したら、**Claude Code に「AI_Office を削除しました」と伝えてください。**

**第1部から来られた方は、削除しないでください。** そのフォルダが、あなたのAIオフィスそのものです。

# AI_Office フォルダに入っているファイル

- **CLAUDE.md** ：会社のルール。Claude Code が毎回読みます。
- **START_HERE.md** ：開設の進め方。Claude Code が読みます。
- **SETUP_STATUS.md** ：進捗の表。
- **Shared_Assets フォルダ** ：会社の基本情報、資料の作り方、文章の決まり、請求書などのテンプレート。
- **Programs フォルダ** ：作ったプログラムの保存先。
- **.claude フォルダ** ：次の5つが入っています。
  - **settings.json** ：禁止事項の設定。
  - **rules（3本）** ：Claude Code が常に守るルール。
  - **skills（9本）** ：スキル（仕事の手順を書いたファイル）。開設の進行役、AI従業員の作り方、裏の取り方など。
  - **settings-template.jsonc** ：禁止事項を書き足すときの見本。
  - **OFFICE_KIT_VERSION** ：このキットのバージョン番号。新しいバージョンがリリースされたかを確かめるときに使います。

**.claude は隠しフォルダです。** エクスプローラーの表示設定を変えないと見えませんが、なくなったわけではありません。
