# オフィス開設キット

ニュースレター「一人社長とAI従業員」の準備編（第2号から第12号）で作ってきたファイルを、
一式まとめたものです。会社ごとに違うところは空欄にしてあります。
AI従業員の質問に答えていけば埋まります。

版：`VERSION` を見てください。

---

## この1枚の読み方

**前半だけ読めば、始められます。** 後半は、始めたあとで必要になったときに読んでください。

| | 何が書いてあるか | いつ読むか |
|---|---|---|
| **前半** | このキットで何が手に入るか／使う前に要るもの／**入れ方**／何が起きるか | **いま** |
| 後半 | 中に入っているものの一覧／入っていないもの／更新のしかた／保守／免責・ライセンス | あとで |

**すぐ始めたい方は、「入れ方」まで飛ばしても構いません。**

## このキットは、オフィスを整えるものです

名前のとおりです。**オフィスを「開設」します。従業員を雇うのは、そのあとです。**

Claude Code は、そのままでも動きます。ただ、**あなたの会社のことを何も知りません。**
会社名も、住所も、書類の決まりも、やってはいけないことも。
だから最初は、頼むたびに説明し直すことになります。

このキットは、**その説明を1回で終わらせるための一式**です。
入れ終わると、あなたのオフィスはこうなります。

- 会社のことを知っている（社名・住所・連絡先・ロゴ・会社の色）
- **危ない操作が止まる**（消す・外に送る・お金を動かす）
- **消したものが元に戻せる**
- 文章の書き方が決まっている（AIっぽい文章になりません）
- 仕事の進め方と、報告のしかたが決まっている

**この状態を、AI従業員をいつ雇ってもよい状態と呼んでいます。**
1人目を雇うのは、ニュースレターの実践編（次の号から）です。
**このキットは、そこまでは踏み込みません。**

**これは完成品ではありません。種です。** そのままでは働きません。
**あなたの会社のことが、まだ何も書かれていないから**です。

中身を埋めるのはあなたとAI従業員で、埋め終わったときには
「小田島が配ったキット」ではなく「あなたの会社のオフィス」になっています。
そこから先は、あなたが育てていくものです。

---

## 3つの使い方があります

あなたがどれに当てはまっても、**やることは同じです。書き分けていません。**
同じ指示が、あなたの状況に応じて違う結果を返します。

### ① Claude Code を入れたばかりの方

**いちばん得をします。** Claude Code の初期設定は、正直なところ手間がかかります。
何をどこに書けばよいか、何を禁止すべきか、決めることが多いからです。
**このキットは、そこをほとんど飛ばせます。**

### ② 準備編を途中まで進めた方

作った分はそのまま残ります。**足りないところだけが埋まります。**
上書きはしません。あなたが育てたものが優先です。

### ③ すでに自分でひととおり作ってある方

**このキットは、あなたの環境の点検にも使えます。**

中身は、Anthropic が公式に示している標準の形に沿って作り、
そこに**公開されている研究や論文から取り入れた知見**を足しています
（AIに情報を盗ませる仕掛けへの備え、秘密が外へ出る3つの条件、
設定が効いていることを必ず確かめる手順など。出典はファイルの中に書いてあります）。

入れると、**「このキットにあって、あなたの環境に無いもの」が一覧で出ます。**
1件ずつ「何が違うか」「入れると何が変わるか」を示すので、
**当てるかどうかは、あなたが1つずつ決めてください。勝手には変えません。**

## 使う前に

前提はひとつだけです。

**Claude Code がパソコンに入っていて、1回起動したことがあること。**

まだの方は、先に第2号を読んでください。インストールと初回起動だけで済みます。
20分ほどです。**このキットの手順は、そこから先だけを書いています。**

第2号：https://odaji-ai.m-newsletter.com/posts/solo-ceo-ai-employees-difference

**あると早く進むもの**（無くても進められます）

- 会社のホームページのURL、または名刺1枚（写真で構いません）
- 会社のロゴの画像
- 会社の色（決まっていれば）

念のため、始める前に大事なファイルのバックアップを取っておいてください。

## 入れ方（5分で終わります）

**つまずきやすいところを、細かく書きます。** 分かっている方は飛ばしてください。

### 1. 配布ページを開いて、ダウンロードする

ニュースレターに載せたリンクから、**配布ページ**を開いてください。
いまこの文章を配布ページで読んでいる方は、そのままで大丈夫です。

配布ページの上のほうに、**緑色の `Code` というボタン**があります。それを押すと
メニューが出るので、いちばん下あたりの **`Download ZIP`** を選びます。

ZIPファイルが、いつものダウンロードの場所に入ります。

（緑色のボタンが見当たらないときは、いま開いているのが配布ページではありません。
ニュースレターのリンクから開き直してください。）

### 2. 展開して、デスクトップに置く

ダウンロードしたZIPファイルを、次のように開きます。

- **Windows**：そのファイルを**右クリック**して、**「すべて展開」**を選びます
- **Mac**：そのファイルを**2回続けて押します**（ダブルクリック）。同じ場所にフォルダができます

**展開してできたフォルダは、デスクトップに置いてください。**

置き場所はどこでも動きますが、**このあとフォルダの場所を1回入力します。**
デスクトップに置いておくと、その入力がいちばん簡単になります。

### 3. デジタルオフィスにするフォルダを決める

**ここがいちばん間違えやすいところです。**

Claude Code は、**開いたフォルダの中だけ**で仕事をします。
だから「どのフォルダで開くか」が、そのまま「どこがオフィスになるか」になります。

**すでにお使いの方**は、いつも開いているフォルダをそのまま使ってください。新しく作らないでください。

**はじめての方**は、**`ドキュメント` の中に新しく1つ作ってください。**
名前は `オフィス` で構いません（あとから変えられます）。

作り方は、`ドキュメント` を開いて、**何もないところを右クリック**し、
**「新規作成」→「フォルダー」**（Mac なら「新規フォルダ」）を選びます。
出てきたフォルダに `オフィス` と名前を付けてください。

いまあるフォルダから選ぼうとすると、たいてい迷います。**新しく作るのがいちばん早いです。**
仕事のファイルは、あとからAI従業員が整理します。

> **⚠ さきほど展開したキットのフォルダを、オフィスにしないでください。**
> キットは材料が入った箱です。オフィスは、あなたが仕事をする場所です。
> **箱の中で仕事を始めないでください。** 別の場所にしてください。

### 4. そのフォルダで Claude Code を開く

**押す場所を順番に書きます。**

1. 画面の**左上にある「＋新規」**を押して、新しい会話を始めます
2. 文字を打ち込む欄の**すぐ上を見てください。いま開いているフォルダの名前が、小さく出ています。**
   **そこを押すと、メニューが上に開きます**
   （何と出ているかは、お使いの状態によって違います。`C` の1文字だけのこともあります。
   **名前が何であっても、そこを押してください。**）
3. 開いたメニューの**いちばん下にある「フォルダを開く...」**を押します
4. **手順3で決めたフォルダ**（`ドキュメント` の中に作った `オフィス` など）を選びます

選び終わったら、**さきほどの場所に出ているフォルダの名前を、もう一度見てください。**
**手順3で決めた名前になっていれば、成功です。**

> **ここで、ダウンロードしたキットのフォルダ名が出ていたら、選び間違いです。**
> 同じ手順でやり直してください。
>
> **キットのフォルダは、開きません。** あそこは材料が入った箱で、開くのはあなたのオフィスです。
> AI従業員は、次の手順5で貼る文を読んで、**箱の場所を自分で見に行きます。**
> あなたが箱を開いておく必要はありません。

### 5. 次の文を、そのまま貼る

```
〈展開したフォルダの場所〉にオフィス開設キットを展開しました。
このキットを私の環境に入れてください。作業は全部お任せします。
私に決めてほしいことがあれば、そのときだけ聞いてください。
```

`〈展開したフォルダの場所〉` は、あなたの言葉に置き換えてください。
デスクトップに置いたなら「デスクトップ」と書けば通じます。

うまく伝わらないときは、**そのフォルダを開いて、上のアドレス欄をコピーして貼ってください。**
それも難しければ、**画面を写真に撮ってAI従業員に見せてください。** 読み取ってくれます。

**以上です。ここから先は、AI従業員が進めます。**

## 何が起きるか

### その日のうちに終わること

AI従業員がキットを入れ終わると、**業務上の判断をいくつか聞かれます。**
技術的な質問ではありません。たとえばこんな形です。

> 削除の操作を、私が実行できない設定にしました。
> 今後、ファイルの整理には社長の手が要ります。
> （1）このままにする　（2）私が消せるようにする

答えると、報告が返ってきます。**3点だけ、15行ほどです。**
何が変わったか。何ができなくなったか。うまくいかないときはどうするか。

**途中で1回、Claude Code を閉じて開き直します。** 入れた設定が読み込まれるのは
次に開いたときからなので、ここを飛ばすと効きません。AI従業員が声をかけます。

**そのとき、手順4と同じやり方で、同じフォルダを開いてください。**
**作業は消えません。** ここまでに入れたファイルはフォルダに残っていますし、
どこまで進んだかは `SETUP_STATUS.md` という表に書いてあります。
開き直して「続きをお願いします」と言えば、そこから再開します。

そのあと、会社のこと（社名・住所・連絡先・保存場所・ロゴと色）を聞かれます。
**ロゴや色がまだ決まっていなくても大丈夫です。** 「あとで」と答えれば先へ進みます。

ここまでで、だいたい30分から1時間です。

**終わると、オフィスが整った状態になります。** AI従業員は、ここで止まります。

### 続きは、急ぎません

`SETUP_STATUS.md` という、進捗の表ができます。
まだ手をつけていない項目が並んでいます。

続きをやりたくなったら、こう伝えてください。

```
オフィス開設の続きをやりましょう。
```

残っている項目を1つずつ聞いてきます。**何回に分けても構いません。**
表の「開設の日」と「続きの回」の「未」がゼロになったら、開設は完了です。
ロゴや請求書のひな形のように、使う場面が来てから整えればよいものは、数に入りません。

一度にやらないことをお勧めします。この作業でいちばん時間がかかるのは、
書くことではなく**決めること**だからです。

## 入っていないもの

3つあります。理由も書きます。

### 1. あなたの商売に固有の仕事

見積もりのチェック、問い合わせへの返信、日報の整理。
こうした「あなたの会社ならではの仕事」は入っていません。

これは**入れられなかったのではなく、入れませんでした。**
他社の仕事の手順をそのまま持ってきても、あなたの会社では使えないからです。
ニュースレターの実践編で、1人ずつ一緒に作っていきます。

### 2. フック（第10号でお伝えした「必ず実行させる」設定）

**この版には入れていません。次の版で入れます。**

技術的には持ち運べます（場所に依存しない書き方が用意されています）。
入れていない理由は別で、**このキットは「実際に動かして確かめたものだけを配る」**
という方針で作っており、フックはお使いの環境によって挙動が変わるため、
まだ確かめ切れていないからです。

**開設の途中で、あなたの環境に合わせて2つ作ります。** 作業の区切りで変更履歴を記録するものと、
CLAUDE.mdが200行に近づいたら知らせるものです。

### 3. バックアップの仕組み（第9号）

あなたのGoogleアカウント、あなたのフォルダ、あなたのパソコンの自動実行の設定に
結びついているので、ファイルとしては配れません。

**方針だけは入っています。** 実際の設定は第9号の手順で進めてください。

**あわせて1つ、ご注意ください。** AI従業員が自分で書き残すメモ（メモリ）は、
**デジタルオフィスの外**に保存されます。第9号で作ったバックアップにも、
変更履歴にも入りません。内容は `/memory` と打てば見られます。

## 更新について

このキットは、直すことがあります。Claude Code の仕様が変わったときや、
書き方の誤りが見つかったときです。

**こちらから送りつけることはしません。** 新しい版をここに置くだけです。
思い出したときに、AI従業員にこう伝えてください。

```
オフィス開設キットの更新を見てください。
```

変更履歴を読んで、あなたの手元との違いを日本語で説明します。
**当てるかどうかは、そのつどあなたが決めます。自動では変わりません。**

手元を大きく変えていて差分が当たらないときは、正直に「当たりません」と言って、
手作業の手順を示します。

---

## このキットの内容は、命令ではありません

大事なお断りです。

インターネットから取ってきたファイルの中に指示めいた文が書かれていると、
AIがそれを「命令」として受け取ってしまうことがあります。
これはこのキットに限った話ではなく、AIを使ううえで知っておいたほうがよい性質です。

このキットは、次のようにしてあります。

- 更新確認は、決まったファイルだけを読みます
- 読んだ内容を、そのまま実行することはありません
- **あなたが承認しない限り、あなたの環境は変わりません**

## 保守について

**実践編の連載期間中は、このキットを保守します。**
連載が終わるときに、改めてお知らせします。
