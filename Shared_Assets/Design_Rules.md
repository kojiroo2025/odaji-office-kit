| スライドの最小の大きさ | 14pt（キットの既定値） |

**最小の大きさは、キットの既定値を入れてあります。変えるときも、必ず何かの値を決めておいてください。** これが無いと、内容を詰め込むために

## 作るときの決まり（キットの既定値）

- **PDFは「印刷」ではなく「書き出し（エクスポート）」で作ってください。** 印刷で
  作ったPDFは、文字が機械で読めなくなることがあります（応募書類を機械で読む
  仕組みなどに読まれません）。できたPDFから文字を全部取り出し、元のファイルの
  文字と突き合わせて、欠けた文字が無いかを確かめてください。そのうえで、該当の
  ページを目でも見てください。表の1行がページの境目で割れて、文字が消えることもあります
- **図は、本文の要約のために置かないでください。** 文章では順番にしか言えない
  関係を、一目で見せるために置きます。直前の箇条書きを絵にしただけの図は
  置きません。図は、結論を言い切る前に置きます
- **社長が「元に無い情報を足さない」「骨組みを変えない」と言ったら、道具の
  既定の作り方（背景の説明を足す、見出しを増やす、など）を当てはめないで
  ください。** 社長の指示が、道具の既定より優先です

## 決め方（まだ埋まっていないとき）

AI従業員にこう頼んでください。

```
会社のロゴ画像を、共通資料のフォルダに置きました。今後、資料を作るときは
これを資料の右上に表示してください。あわせて、ロゴの色をもとに、
デザイン仕様をファイルにまとめたいです。使う色、文字の大きさの下限、
見出しの付け方など、決めておくとよい項目を挙げてください。それを見て
私が具体的に指示します。判断がつかない項目は、あなたの案を理由つきで
示してください。
```

ロゴがまだ無ければ、こう伝えてください。

```
会社のロゴはまだありません。ロゴの欄は「未定」としておき、
デザイン仕様だけ先に作ってください。
```

**ここでは最低限だけ決めてください。** 提案書の細かい構成や、より高度な
デザインは、実際に資料を作る段になってからで間に合います。
