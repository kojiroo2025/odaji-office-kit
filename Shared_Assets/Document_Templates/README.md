# 書類のひな形の置き場

**このフォルダは空です。あなたの会社で使っている書類を、ここに入れてください。**

いきなり「請求書を作って」と頼むと、思ったものとは違うものが出てきます。
いま使っているひな形をここに置くところから始めます。

---

## 入れるもの

いま実際に使っているファイルを、そのまま置いてください。Excel でも Word でも
構いません。作り直す必要はありません。

- 請求書
- 見積書
- 納品書
- 領収書
- 契約書
- 発注書

種類が増えてきたら、下にフォルダを作って分けてください。分け方の案は
AI従業員に出させてよいですが、決めるのはあなたです。

## 入れないもの

**発行済みの書類は、ここに入れないでください。** ここはひな形の置き場です。
実際にお客様に出したものは、別の場所（お客様ごとのフォルダなど）に保管します。

発行済みの書類には、取引先の名前・金額・条件が入っています。**このフォルダは
AI従業員の全員が読む場所**なので、そうしたものを置かないでください。

---

## 置いたあとに、必ずやること

ひな形を置いたら、先に作った2つのファイルと突き合わせてください。

```
保管したテンプレートを、Company_Info.md と Design_Rules.md と比較してください。
記載内容の食い違い、書式の不統一、適格請求書（インボイス）の記載要件で
足りない項目があれば指摘してください。直す前に、修正するべき点の一覧を
私に見せてください。
```

**何年も使ってきた自社のひな形の不備が、ここで見つかることがあります。**
基本情報とデザイン仕様と突き合わせたからこそ見つかるズレです。
参照先をそろえた効果が、最初に目に見える瞬間になります。

直すときは、元のファイルを残してください。

```
では、指摘のうち〇〇と〇〇を直してください。
元のファイルは残し、直したものを別名で保存してください。
```

**インボイスの記載要件についてAI従業員が示した判断は、最終的に顧問の税理士に
確認してください。** AIの判断で税務の結論を出さないでください。

---

## 渡したあとの書類を直すとき

お客様に渡したあとの資料を直すときは、**直すように言われた部分だけを、
別のファイルで**作ってください。原本を丸ごと作り直さないでください。
原本には、社長が手で加えた細かい直しが入っていることがあり、作り直すと
それが消えます。社長が「全部作り直して」と言ったときだけ、作り直します。

## ひな形を複製するとき

複製すると、一覧に出ない付属物（ひも付いたマクロや、共有の設定など）も
一緒に写ることがあります。付属物を付け直すなら、いったん付属物を外した
複製から始めてください。「前はうまくいった」は、前と同じ手順だったときにだけ
安心の材料になります。

---

## ひな形が手元に無いとき

一から作ってもらえます。

```
請求書のテンプレートが手元にありません。適格請求書（インボイス）の
記載要件を満たす形で、Company_Info.md と Design_Rules.md を参照して、
Excelでたたき台を作ってください。まず、どんな項目をどう並べるかの案を
示して、私の確認を得てから作成してください。
```

やり取りしながら整えて、決まったらこのフォルダに保存してください。
