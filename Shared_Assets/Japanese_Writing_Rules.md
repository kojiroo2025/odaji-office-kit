# ① 読みやすい日本語

**対象は、まとまった文章の本文です**（メール・提案書・ブログ・お知らせ・社内文書）。
手順書・表・チェックリスト・箇条書きの一覧は、対象ではありません。

## 1-1　1つの文に、1つのことだけ書く

文が長くなるのは、2つ以上のことを1文に詰め込んでいるからです。

> 修正前：弊社では、創業以来培ってきた品質管理のノウハウを活かし、お客様の
> ご要望に柔軟にお応えするとともに、納期の短縮にも取り組んでおります。
>
> 修正後：弊社は創業以来、品質管理のノウハウを積み上げてきました。
> お客様のご要望に合わせて仕様を変えられます。納期の短縮にも取り組んでいます。

全角50字を超える文が3つ続いたら、分けてください。

## 1-2　打ち消しを重ねない

読む人が、頭の中で2回ひっくり返すことになります。

> 修正前：この方法が使えないわけではありません。
>
> 修正後：この方法も使えます。

**ただし、本当に決まっていないことは、決まっていないまま書いてください。**
断定できることを弱めているときだけ、言い切る形に直します。

> そのまま残す例：原因は通信かもしれませんし、設定かもしれません。（まだ調べていない）
>
> 直す例：まだ決まっていないかもしれません。→ まだ決まっていません。（決まっていないことは分かっている）

## 1-3　遠回しな言い方を短くする

意味は増えないのに、文だけが長くなります。

| 直す前 | 直したあと |
|---|---|
| 〜することができます | 〜できます |
| 〜を行います／〜を実施します | 〜します |
| 〜という形になります／〜といった形で | 〜します（または削る） |
| 〜させていただきます | 〜します |
| 〜になります | 〜です |
| 〜の方（ほう）を | 〜を |
| まず最初に／約〜ほど／各〜ごとに | まず／約〜／各〜（同じ意味が重なっています） |

> 修正前：資料をご確認のうえ、ご返送を実施していただく形になります。
>
> 修正後：資料を確認して、返送してください。

## 1-4　だれが・何を、を書く

主語と目的語を省かないでください。とくに文の最初と、話が変わるところで書きます。

> 修正前：対応が遅れたため、変更しました。
>
> 修正後：こちらの対応が遅れたため、納品日を変更しました。

## 1-5　「これ」「その」が指すものを、同じ文の中で分かるようにする

初めて出すときは、指し示す言葉ではなく、名前で書いてください。

## 1-6　かなで書く語

こと・とき・もの・ところ・すべて・ぜひ・ください・できる は、かなで書きます
（「事」「時」「下さい」「出来る」と書きません）。
**固有名詞・専門用語・かなにすると意味が変わる語は、そのままにします。**

# ② 専門用語の出し方

**ここがいちばん大事です。** やさしく書こうとして言葉を置き換えると、
かえって何の話か分からなくなります。

**決まりは1つだけです。**

> **専門用語は、日本語にも、ふだんの言葉にも置き換えない。そのまま使う。**

**例外は1つ。その言葉が一般的ではないと判断したときだけ、次のどちらかを添えます。**

1. **わかりやすい説明を、初めて出すときだけ1文添える**（括弧で）
2. **たとえで表す**（使うかどうかは、下の 2-2 の2つの問いで決めます）

**添えるのであって、取り替えるのではありません。** 言葉は必ず残します。

**「分からないかもしれないから言い換えておく」は、原則にも例外にも当てはまらない
間違った直し方です。** 迷ったときは、そのまま使って説明を1文添えるほうを選んでください。

> 悪い例：進捗を管理する表 → 進み具合の表（何の進み具合か、何をする表か、分からなくなりました）
>
> 良い例：進捗を管理する表（そのまま）
>
> 良い例：API（ソフトの機能を外部から使えるようにする窓口）に接続します

## 2-1　置き換えは、2つの方向で起きます

「やさしくしよう」と思った瞬間に、次の2つが起きます。**片方だけを気をつけても、
もう片方から同じことが起きます。**

| 方向 | 例（左が間違い） |
|---|---|
| 専門用語 → ふだんの言葉 | 進み具合←**進捗** ／ 置き場←**保存先** |
| **広まっている外来語 → 日本語** | 窓←**ダイアログ** ／ 文字を打つ欄←**入力フィールド** ／ 道具←**ツール** ／ 引っぱって離す←**ドラッグアンドドロップ** |

下のほうは、日本語にしたほうがやさしいという思い込みから出ます。**でも読む人は、
画面でその外来語に実際に出会います。** 日本語に置き換えると、画面と文章が食い違って、
かえって手間が増えます。

**判定は上の1問のままです。** その言葉が漢語か、和語か、外来語かは、判定に使いません。

## 2-2　たとえを使うかどうか（問いは2つ）

**たとえを使うこと自体が目的ではありません。** そのまま説明して分かるなら、正確な言葉の
ほうが手がかりになります。**難しくて分かりにくいと判断したから、たとえで助けます。**

> **問1　そのまま説明して、読む人は分かるか。**
> **分からない → たとえを使う**
> 分かる → 問2へ
>
> **問2　読む人がまだ気づいていない性質を、そのたとえが1つ運べるか。**
> **運べる → 分かっていても、あえて使う**（理解が深まります）
> **運べない → 使わない**（分かっていることを言い替えるだけになります）

**見分け方があります。**

> **そのたとえを打ち消す但し書きを書きたくなったら、運べていません。外してください。**

**もう1つ。読む人がまだ持っていないものを、たとえにしないでください。**
まだ作っていないものが動くことになり、読む人は「自分はまだそれを作っていないが」と
引っかかります。手順書では、たとえよりもソフトの名前のほうが正確なことが多くあります。
操作する相手は、たとえではなく画面の中のソフトだからです。

**順番は必ず、言葉 → 説明 → たとえ です。** いきなりたとえから始めないでください。
たとえは理解の助けであって、説明の代わりではありません。
件名・見出しにたとえを置かないでください（説明を挟む場所がないためです）。

## 漢語について

**漢語を別の言葉に置き換えるのは、下の表に載っている語だけです。**
表にない漢語は、そのまま使ってください。

| 直す前 | 直したあと |
|---|---|
| 具現化する | 形にする |
| 惹起する | 引き起こす |
| 勘案する | 考え合わせる |
| 奏功する | うまくいく |
| 齟齬 | 食い違い |
| 漸次 | 少しずつ |

一般的な漢語（実施する・確認する・提供する・進捗・設定・履歴・権限 など）は、
そのままで構いません。**固いと感じたときは、言葉を取り替えるのではなく、
文を分ける・だれが何をしたかを書く、で直してください。** 固さの正体は言葉ではなく、
1文に詰め込まれた情報の多さです。

# ③ AIっぽい文章を避ける

**物差しは1つです。**

> **その言葉を削っても、言いたいことは減らないか。**

減らないなら、それはAIっぽさです。削ってください。

| やめる | なぜ |
|---|---|
| 「本章では〜を扱います」「ここでは〜を見ていきます」 | 内容の代わりに、これから何を書くかを言っているだけ |
| 「不可欠」「核心的」「鍵となる」「多角的」「包括的」 | 強めているだけで、何がどうなのかを説明していない |
| 「掘り下げる」「深掘りする」「言及する」「触れる」 | 何を書いたかを示さずに終わっている |
| 「〜かもしれません」「〜ではないでしょうか」 | 根拠があるのに弱めている（本当に未確定なら残す。1-2を参照） |
| 「非常に」「極めて」「とても」の多用 | 程度ではなく、事実で示す |
| 「重要なのは」「大切なのは」 | 1本に1回まで（1通のメール・1本の記事・1章） |

**言葉を1つずつ禁じるのではなく、上の物差しで見てください。**
単語だけを禁じると、同じことを別の言い方に置き換えるだけになります。

## 3-1　ダッシュ（`——`）を使わない

**これは言い回しではなく、文字の話です。** AIは日本語を書くときに、英語の書き方を
そのまま持ち込んで、文の途中にダッシュ（`——` `―` `—`）を入れます。日本語の文章では
ほとんど使われない書き方なので、読んだ人に「AIが書いた」と伝わります。

> 直す前：お金を動かすこと ―― あなたの環境に合わせて足します
>
> 直したあと：お金を動かすこと（あなたの環境に合わせて足します）

**地の文・見出し・表題では使いません。** 言い直しや補足を入れたいときは、
括弧に入れるか、句点で2つの文に分けるか、読点でつなぎます。

対象外：フォルダの図に使う罫線（`├─` `└─`）は、形が似ていますがダッシュではありません。
日付や番号をつなぐ半角のハイフン（`2026-09-12`）も、そのまま使います。

## 3-2　ものの動きにたとえた動詞を使わない

AIは、頭の中の働きや、機械の処理を書くときに、**ものが動くようすにたとえた動詞**を
使いがちです。読むと、そこだけ調子が変わって「AIが書いた」と伝わります。

| 直す前 | 直したあと |
|---|---|
| 「問題なし」のほうへ**流れます** | 「問題なし」と**判断してしまいます** |
| 検査を**走らせます** | 検査を**実行します** |
| 記録に**載せます** | 記録に**書きます** |
| 決まりに**効きます** | 決まりが**当てはまります** |

**見分け方：その動詞が、もともと体や物の動きを表す言葉かどうか。**
流れる・走る・回す・叩く・投げる・拾う・落とす・刺さる・効く などが当てはまります。
考えることや、機械の処理には、そのままの言葉（判断する・実行する・記録する）を使います。

## 3-3　動詞が、その言葉と結びつくかを確かめる

> **その言い方を、その分野の人が実際に使うか。**

使わないなら、使う言い方に直します。**名前が正しくても、動詞が結びついていないと
日本語になりません。**

| 直す前 | 直したあと |
|---|---|
| 変更履歴を**始める** ／ 仕組みを**始める** | 記録を**開始する** |
| 資料を**埋める** | 資料に**記入する** |
| ダイアログが**出る** ／ **出た**窓 | ダイアログが**表示される** ／ **表示された**ダイアログ |
| 控えを**強引に**上書きする | 控えを**強制的に**上書きする |
| 情報を**渡す** ／ 色を**渡す** | 情報を**伝える** ／ 色を**伝える**（指示する） |
| 決まりが**破れている** | 決まりが**当てはまらない** |

**「渡す」は、物を手渡すときの言葉です。** 情報・指示・色・方針のように**形の無いものには
使いません。** 同じ理由で、決まりや約束に「破れる」（物が裂ける）を使いません。

3-2 とは別のものです。3-2 は、たとえが現実と噛み合っていない場合です。
こちらは、**たとえではないふつうの動詞**が、その言葉の慣用と合っていない場合です。

書き方の例（埋まってきたら、こんな形になります）：

```

```

**あなたが決めた言葉や表記は、①②③の一般的な決まりより優先します。**

## 手順書を書くときの2つ（①〜④とは別に、追加で当てはまります）

読む人が**そのとおりに操作する**文書（手順書・マニュアル・社内の作業手順）を書くときは、
次の2つが追加されます。

**1　読む人への約束は、実装を確かめてから書く**

> **その動作をさせる指示が、実際にどこかのファイルに書いてあるか。**

書いていなければ、その約束は成立しません。**書くのをやめるか、先に指示のほうを足してください。**

「〜が確認します」「〜が1件ずつ示します」と書いても、そう振る舞わせる指示がどこにも
無ければ、そのとおりには動きません。**読む人は、書いてあるとおりに動くと思って待ちます。**

**2　説明は、読む人がその操作をする場所に置く**

先に書いても、あとに書いても、**操作しているその瞬間に目に入らなければ読まれません。**
大事な注意ほど、手順の最後にまとめず、**その手順の中に置いてください。**

## このファイルの育て方

- 決まりを足すときは、**どこまで当てはまる決まりなのかを必ず書いてください**
  （すべての文章か、本文だけか、メールだけか）。範囲を書かない決まりは、
  当てはめすぎて、かえって読みにくい文章を作ります
- 同じことを2か所に書かないでください。2か所あると、片方だけ直って食い違います
- 決まりが増えて読まれなくなるより、少なくて守られるほうが、良い文章が出ます
