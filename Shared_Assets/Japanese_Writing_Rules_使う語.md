`Japanese_Writing_Rules.md` の ②（2-3・2-4）と ③（3-3）で使うデータです。

- **書くときに見るのは、この一覧です。** 場面に合う語を、名詞と動詞の組で使います。
  一覧にない語も、`Japanese_Writing_Rules.md` 2-3 の1問（受け取る人が自分の職場で使う語）で判定します
- 「代わりに使いがちな語」の列は、AI の文章に実際に出やすい語です。**禁止の一覧として、
  機械的に置き換えないでください。** 「書き直す」「見直す」「会議を開く」「送る」のように、
  業務の文書でも使う和語は、文脈に合えば使います
- 「確認する・検証する・評価する・診断する」は、同じ意味の語として交換しません。作業の中身で使い分けます
- 画面に表示される正式な名前は、その表示に合わせます

## 専門用語の L1・L2

区分の考え方は `Japanese_Writing_Rules.md` 2-4 にあります。

- **L1**＝そのまま使い、原則として説明は要りません
- **L2**＝そのまま使い、独立して読まれる文書ごとに、初出で説明を添えます
- 説明の列は、その語が何かを文字どおりに書いた文案です。文脈に合わせて長さを調整して構いませんが、意味は変えません
- たとえは、説明のあとに添えます（使うかどうかは `Japanese_Writing_Rules.md` 2-2）

| 区分 | 用語 | 初出で添える説明 | 意味の範囲・注意 |
|---|---|---|---|
| L1 | パソコン／ソフト／アプリ／インストール／ファイル／フォルダ／データ／保存／設定／更新／メール／インターネット／Webサイト／URL／検索／クラウド／アカウント／パスワード／ログイン／セキュリティ／バックアップ／テンプレート／AI／生成AI／ChatGPT／チャット／サーバー／管理画面／コマンド／パス／スクリーンショット |  | 原則として説明は要りません |
| L2 | Claude Code | パソコンにインストールして使い、指示に従ってファイルの作成・編集やコマンドの実行まで行う AI のツール |  |
| L2 | CLAUDE.md | Claude Code が作業のたびに読み込む、会社の方針とルールを書いたファイル |  |

| L2 | フック（hooks） | 指定したタイミングで、決めた処理を自動で実行させる設定 |  |
| L2 | ルール（Claude Code の機能） | CLAUDE.md の内容を、テーマごとに分けて置く別のファイル | ふつうの言葉の「ルール」と区別できるよう、初出で機能の名前だと分かるように書きます |

| L2 | 権限（permissions）・deny | AI に許可する操作と、禁止する操作を決める設定 |  |

## 名詞と動詞の組み合わせ

1つの名詞に1つの動詞を対応させません。作業の中身で動詞を選択します。

| 名詞 | 使う動詞（作業の中身で選択） | 例文・注意 |
|---|---|---|
| 変更履歴 | 記録を開始する | Git が変更履歴の記録を開始します。 |
| 仕組み | 運用を開始する／構築する | 担当者が新しい受付の仕組みの運用を開始します。 |
| 資料 | 作成する／（資料に）記載する。申請書などの欄に書くときは「記入する」 | Claude Code が資料を作成し、調査結果を記載します。担当者が申請書の氏名欄に記入します。「資料を記入する」とは書きません |
| ダイアログ | 表示される | 保存の確認のダイアログが表示されます。 |
| ファイル | 上書きする | 利用者がファイルを上書きします。「強制的に」は、通常の制約を外して上書きする操作を説明するときだけ添えます |
| 情報・指示・方針 | 伝える・示す・指示する | Claude Code が変更の方針を示します。プログラムにデータを渡すような技術の分野で定着した組み合わせ（引数を渡す）は使います |
| 色 | 指定する／伝える | 担当者が見出しの色を指定します。 |
| ルール・約束 | 違反なら「ルールに違反する」、守られていないなら「約束を守っていない」、対象外なら「このルールは適用されない」 | 「破れる」は使いません。3つは意味が違うので、文脈で書き分けます |
| プログラム | インストールされている | 「入っている」は位置、「含まれている」は中に含むことを表します |
| 回答・意見 | 反映する | Claude Code が回答を議事録に反映します。 |
| 台帳・記録 | 追記する | Claude Code が承認日を台帳に追記します。 |
| 会議 | 開催する | 「開く」も使えます。パソコンの操作の説明では、ファイルを「開く」と紛れるので「開催する」 |
| 一覧・表と会計ソフト | 登録するのはデータ（経費を会計ソフトに登録する）。ファイルを取り込む操作なら「インポートする」 | 「一覧を会計ソフトに登録する」は、ファイルを取り込むのか、中身を入力するのかが決まりません |
| 録音ファイル | 文字起こしをする | 文字起こしのツールが録音ファイルから文字起こしをします。 |
