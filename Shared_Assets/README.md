# 共通資料のフォルダ

**AI従業員の全員が参照するファイル**を置く場所です。
第11号「あなたの会社の基本情報を、デジタルオフィスに登録する」で作ったものです。

AI従業員が1人だけなら、これは無くても足ります。毎回その1人に伝えれば済むからです。
**2人目、3人目と増えたときに効いてきます。** 提案書を作った従業員と、
それを要約した従業員とで、肩書きの表記が違う。ある従業員は見出しを青にし、
別の従業員は緑にした。こうしたズレを、増える前に止めます。

---

## 入っているもの

| ファイル | 何を書くか | いまの状態 |
|---|---|---|
| `Company_Info.md` | 会社の基本情報 | **枠だけ。** あなたが埋めます |
| `Design_Rules.md` | 使う色、文字の大きさ、見出しの付け方 | **枠だけ。** あなたが埋めます |
| `Japanese_Writing_Rules.md` | 文章の書き方 | **①②③は記入済み。④は空欄** |
| `Document_Templates/` | 請求書・見積書などのひな形 | **空。** あなたのものを入れます |
| `Injected_Instructions.md` | 外から来た文章に紛れ込んでいた指示の記録 | **キットには入っていません。** 見つけたときに、AI従業員が作ります |

## ロゴ画像は、このフォルダの直下に置いてください

第11号で、ロゴ画像を共通資料のフォルダに置くようご案内しました。
このフォルダの直下に、そのまま置いてください。

```
Shared_Assets/
  ├─ logo.png        ← ここ
  ├─ Company_Info.md
  ├─ Design_Rules.md
  └─ …
```

置いたら、`Design_Rules.md` に「資料を作るときはロゴを右上に表示する」と
書き加えてください。**置くだけでは使われません。**

ロゴがまだ無ければ、飛ばして構いません。`Design_Rules.md` のロゴの欄を
「未定」にしておいてください。

---

## 作っただけでは、使われません

**AI従業員がこのフォルダを見るように、指示しておく必要があります。**
まだであれば、こう伝えてください。

```
共通資料のフォルダに置いた Company_Info.md、Design_Rules.md、
Japanese_Writing_Rules.md、Document_Templates の4つを、今後あなたが
必ず参照するようにしたいです。どのファイルを、どんな作業のときに
参照すべきかを整理して、その方針を書き込んでください。書き込む先は、
CLAUDE.md本体とルールのどちらが適切かを判断してください。
CLAUDE.md本体が長くならないようにしてください。
```

---

## ここに入れてはいけないもの

`Company_Info.md` に入れるのは、**すでに世の中に公開している情報だけ**にしてください。

- 取引先の名前
- 単価、取引の条件
- 口座番号
- まだ公表していない計画

これらは入れません。第4号でお伝えした、AIに渡してよい情報と渡してはいけない情報の
考え方が、そのまま当てはまります。

**このフォルダは、全員が読む場所です。** 特定の相手にだけ見せたいものは、
ここに置かないでください。
